# 数据库初始化原则（速查版）

> 一句话：**创建数据库那一刻，版本 + 字符集 + 排序规则三件事钉死。**

## 标准值速查

| 数据库 | 版本 | 字符集 | 排序规则 |
|---|---|---|---|
| MySQL 5.7 | `5.7.x` | `utf8mb4` | `utf8mb4_general_ci` |
| MySQL 8.0 | `8.0.x` | `utf8mb4` | `utf8mb4_0900_ai_ci` |
| PostgreSQL | `15/16` | `UTF8` (client) | ICU |
| SQL Server | `2019/2022` | 见 collation | `SQL_Latin1_General_CP1_CI_AS` |

## 标准 CREATE 动作

### MySQL

```sql
CREATE DATABASE my_app
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_0900_ai_ci;  -- 8.0
    -- utf8mb4_general_ci                   -- 5.7
```

### PostgreSQL

```sql
CREATE DATABASE my_app
    WITH ENCODING 'UTF8'
         LC_COLLATE = 'en_US.UTF8'
         LC_CTYPE   = 'en_US.UTF8'
         TEMPLATE   = template0;
```

### SQL Server

```sql
CREATE DATABASE my_app
    COLLATE SQL_Latin1_General_CP1_CI_AS;
```

## 4 种迁移报错（速记）

| # | 报错类型 | 一句话原因 |
|---|---|---|
| 1 | emoji/中文乱码 | 字符集不是 utf8mb4 |
| 2 | ORDER BY 顺序变了 | collation 不一致 |
| 3 | INSERT 雪崩 | sql_mode 严格模式不一致 |
| 4 | 客户端连不上 | 认证插件不一致 |

## 防御检查 SQL

```sql
-- MySQL: 找出非 utf8mb4 表
SELECT table_schema, table_name, table_collation
FROM information_schema.tables
WHERE table_schema NOT IN ('mysql','sys','information_schema','performance_schema')
  AND table_collation NOT LIKE 'utf8mb4%';

-- PG: 找数据库编码
SELECT datname, datcollate, datctype FROM pg_database;

-- SQL Server: 找 collation
SELECT name, collation_name FROM sys.databases;
```

## 原则

```
版本 + 字符集 + 排序规则
            ↓
   CREATE 那一刻写死
            ↓
   之后所有迁移 / 同步 / 多环境一致
```
