## 约定式读书笔记规范Conventional Reading Notes 

 基本结构

这套结构用于你读完一个章节、一个段落或产生一个念头时的记录。

```text
<type>(<scope>): <subject>

[optional body]

[optional footer(s)]

```

 1. Header (必填)

 **type** (笔记类型)

为了量化你的收获，我们将“阅读获得感”分为以下几类枚举值（对应代码的 `feat`, `fix` 等）：

* `concept`: **新概念/新认知**。对应 `feat`。也就是“Aha Moment”，你以前不知道的，或者颠覆你认知的。
* `method`: **方法论/SOP**。对应 `feat` 或 `build`。具体的步骤、工具、公式，可以直接拿来用的。
* `refactor`: **重构思维**。对应 `refactor`。纠正了你过去的某个错误偏见，或者优化了你已有的知识体系。
* `quote`: **金句/素材**。对应 `style` 或 `docs`。精彩的比喻、故事、数据，用于未来写作或表达的素材。
* `doubt`: **疑问/批判**。对应 `fix` (待修复)。你不认同的观点，或读不懂的地方，需要后续查证。
* `link`: **知识关联**。对应 `merge`。让你想起了另一本书或另一件事，产生了连接。

 **scope** (来源范围)

* **格式**：`(书名缩写/章节)` 或 `(页码)`。
* **作用**：方便回溯原文。
* **示例**：`(思考快与慢/Ch1)`, `(原子习惯/p56)`, `(三体)`

 **subject** (核心摘要)

* **要求**：**必须用自己的话**总结，禁止直接复制原文。
* **长度**：50字以内。
* **语气**：陈述事实或行动指令。

 2. Body (可选)

* **费曼阐述**：如果 `subject` 说不清楚，在这里展开。想象你在给别人解释这个概念。
* **背景上下文**：为什么这条知识对你重要？

 3. Footer (可选 - 行动与标签)

这是量化“改变”的关键区域。

* `TODO: <动作>`：具体的行动指令。
* `TAG: #标签`：用于跨书籍的主题检索（如 `#心理学`, `#职场`, `#投资`）。

---

`示例 (Examples)`

 场景 1：学到了一个新概念 (concept)

```text
concept(思考快与慢): 大脑存在系统1(直觉)和系统2(理性)两种模式

系统1是无意识的、快速的，容易产生偏见；系统2是耗能的、慢速的，用于复杂计算。
之所以会做蠢事，是因为我们经常用系统1去处理本该由系统2处理的问题。

TAG: #认知科学 #决策

```

 场景 2：学到了一个具体方法，准备执行 (method)

```text
method(原子习惯/Ch3): 使用“习惯叠加”公式来建立新习惯

公式：继[当前习惯]之后，我将[新习惯]。
利用已有的神经通路来从搭便车，降低启动阻力。

TODO: 每天早上“倒完咖啡”之后，立刻“读2页书”。

```

 场景 3：纠正了过去的错误想法 (refactor)

```text
refactor(纳瓦尔宝典): 财富不是金钱，而是睡觉时也能赚钱的资产

以前认为赚钱就是靠出卖时间（工资），这是错误的。
真正的财富是代码、媒体内容或资本，这些边际成本为零的产品。

```

 场景 4：摘录了一个精彩比喻 (quote)

```text
quote(围城): 婚姻是一座围城，城外的人想进去，城里的人想出来

TAG: #人性 #比喻

```

---

`最佳实践 (Best Practices)`

1. **Subject 必须重写**：
* ❌ `concept(三体): 黑暗森林法则` (太泛，没信息量)
* ✅ `concept(三体): 宇宙社会学认为文明首要目标是生存，且需隐藏坐标` (这才是读懂了)


2. **原子化记录**：
* 一条笔记只讲一个知识点。不要试图在一个 commit 里把整章书都概括完。


3. **定期 Code Review (复盘)**：
* 你可以像查看 git log 一样查看你的阅读历史。
* **量化指标**：
* 本月产出了多少个 `method`？ -> **技能树增长量**
* 本月产出了多少个 `TODO`？ -> **行动转化率**
* 本月有多少 `refactor`？ -> **认知升级次数**

`你的“Git Log”视图`

当你坚持用这个规范记录一段时间后，你的笔记软件（或简单的Markdown文件）看起来会像这样，非常清晰且有成就感：

```text
* a1b2c3d method(原子习惯): 设定“环境线索”以减少坏习惯触发
* e4f5g6h concept(反脆弱): 波动性对脆弱事物是伤害，对反脆弱事物是养分
* i7j8k9l quote(月亮与六便士): 满地都是六便士，他却抬头看见了月亮
* m0n1o2p refactor(沟通): 争论对错在亲密关系中是无效的，情绪价值更重要
* q3r4s5t TODO: 按照《睡眠革命》调整今晚的卧室光线

```

现在，你可以试着用这个格式，为你最近读过的一本书写一条 **Commit** 吗？
